# 초기 설정

## 1. 휴가 종류

연차, 병가, 공가, 특별휴가, 대체휴가 등 사무실에서 쓰는 종류를 모두 등록합니다.

### 잔여 방식

잔여 방식은 **추가할 때 정하고, 사용 기록이 생기면 바꿀 수 없으니** 신중히 고르세요.

- 연도별: 해마다 새로 시작 / 누적: 해를 넘겨 쌓임
- 정한 날짜에 소멸: 매년 소멸일(예: 2월 28일)이 지나면 남은 양이 사라지고 다음 날부터 새로 셈
- 부여 후 기간: 부여일부터 정한 개월 수가 지나면 그 부여에서 남은 양이 사라짐 (먼저 사라질 부여부터 사용)
- 소진: 누적처럼 해를 넘겨 쌓임 (잔여에서 차감하는 종류만). `남은 양이 없으면 휴가원에서 숨김`(기본 켜짐)을 켜 두면 남은 양이 없는 직원(한 번도 부여받지 않은 직원 포함)은 휴가원 작성의 종류 목록과 휴가원 양식(휴가현황 표·체크박스)에서 빠짐. 그 휴가원에서 쓴 종류는 그대로 나오고, 다시 부여하면 다시 나옴

(예: 대체휴가는 누적 또는 부여 후 기간, 특별휴가는 연도별)

### 적용 대상

일부 직원만 쓰는 종류(예: 사회복무요원 특별휴가)는 **적용 대상**을 `소속·구분·직원 선택`으로 바꾸고 소속, 구분, 직원을 고르세요. **소속과 구분을 함께 고르면 둘 다 맞는 직원만** 대상이고(예: `아동사업부` + `직원` → 아동사업부의 직원), 따로 고른 직원은 조건과 관계없이 더해집니다. 다른 직원의 휴가원 작성·부여·잔여 현황에는 그 종류가 나오지 않습니다.

**직원·요원·강사처럼 대상마다 소멸일이 다른 연차**는 종류를 나눠 등록하세요. 이름은 `연차(직원)`·`연차(요원)`·`연차(강사)`처럼 다르게, **표시 이름은 모두 `연차`** 로 하고, 적용 대상은 각각의 구분으로 정합니다. 휴가원과 양식에는 "연차"로 나오고, 부여는 종류마다 따로 합니다. 한 직원에게 "연차"가 둘 이상 적용되게 저장하면 막고 누가 겹치는지 알려 줍니다.

소속·구분으로 고르면 새로 온 직원에게도 자동으로 적용됩니다. 직원으로만 고른 경우에는 새 직원을 휴가 종류 수정에서 따로 추가하세요.

### 양 입력

부여량·잔여량은 `[ ]일 [ ]시간 [ ]분` 칸에 직접 입력합니다 (분은 10분 단위). **1일은 그 직원의 하루 근무시간**입니다 (점심 제외. 09:00~18:00 → 8시간, 10:00~16:00 → 5시간). 연차 15일이면 근무시간과 관계없이 `15일`로 넣으면 되고, 여러 명에게 한 번에 부여해도 직원마다 알맞게 계산됩니다. 60분 이상은 시간으로, 하루 근무시간 이상 입력한 시간은 일로 넘어갑니다.

## 2. 설정

근무시간 기본값과 소속·구분 목록을 정합니다.

- 직원 소속·구분은 이 목록에서 고르므로 직원보다 먼저 등록하세요.
- 사회복무요원 구분을 만들고 `사회복무요원 특별휴가 대상`을 켜야 그 구분의 직원이 사회복무요원 특별휴가·특별휴가(시상) 신청서 대상자로 나옵니다.
- 시간외근무로 적립할 휴가 종류는 설정에서 정하지 않고, **시간외근무 신청서를 쓸 때 대상자마다 고릅니다** (처음에는 비어 있음). 목록에는 그 직원에게 적용되는 활성 종류만 나오므로, 직원용·요원용 대체휴가처럼 대상마다 종류가 따로 있으면 직원에게는 대체휴가(직원), 요원에게는 대체휴가(요원)를 고르면 됩니다. 이미 적립된 신청서도 수정에서 종류를 바꾸면 적립이 바꾼 종류로 다시 만들어집니다.

## 3. 직원

성명, 소속, 색상, 근무 요일, 근무시간, 결재칸(휴가원 결재란에 나올 담당·팀장·센터장·대표), 구분

## 4. 기존 잔여량

프로그램을 쓰기 전까지의 올해 총 부여량과 현재 잔여량 (도입할 때 한 번)

## 5. 부여 내역

올해 부여량 (새해에는 연초에 직접 입력)

## 6. 공휴일·센터 휴무일 확인

빠진 대체·임시공휴일, 센터 휴무일을 추가합니다.
