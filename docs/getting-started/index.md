# 시작하기

leave-flow는 출결 PC 한 대에 설치하고, 사무실의 다른 PC에서는 브라우저로 접속해 씁니다.

1. **[설치](installation.md)** — 출결 PC에 설치 프로그램을 실행합니다.
2. **[접속 확인](../general/network.md)** — 출결 PC의 IP를 확인하고 다른 PC에서 `http://<출결 PC IP>:8080`으로 접속되는지 봅니다.
3. **[처음 설정](first-setup.md)** — 관리 화면에서 휴가 종류·설정·직원·잔여량·부여 내역을 입력합니다.
4. **[NAS 백업](../backup/nas.md)** — NAS 백업 폴더를 지정합니다.

설치한 뒤 서버가 어떻게 켜지고 꺼지는지는 [실행과 트레이](../general/running.md)를 보세요.
