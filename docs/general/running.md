# 실행과 트레이

## 자동 실행

- 설치할 때 이 PC에 로그인해 있던 Windows 계정이 **로그인하면** 자동으로 실행됩니다.
  설치할 때 자동 실행을 껐으면 로그인해도 켜지지 않으므로 바로가기로 켭니다.
- **로그인하기 전에는 서버가 돌지 않으므로** 출결 PC는 운영 시간에 그 계정으로 로그인해 두세요.
- 서버는 그 Windows 계정 권한으로 실행되고, NAS에도 그 계정으로 접근합니다 ([NAS 백업](../backup/nas.md)).

## 트레이 아이콘

실행되면 작업 표시줄 오른쪽 알림 영역(트레이)에 **파란 달력 아이콘**이 생깁니다. 아이콘이 안 보이면 `^`(숨겨진 아이콘 표시)를 누르세요.

- **웹페이지 열기** (아이콘 클릭도 같음): 이 PC의 브라우저로 휴가원 관리 화면을 엽니다. 직원들과 같은 주소(`http://<출결 PC IP>:<포트>`)로 엽니다.
- **종료**: 서버를 끕니다. **다른 PC에서도 접속할 수 없게 되므로** 확인 창이 한 번 더 나옵니다.

## 끄고 다시 켜기

- 종료한 뒤 다시 켜려면 시작 메뉴(또는 바탕화면)의 **leave-flow 휴가원 관리**를 실행합니다 (이미 켜져 있으면 웹페이지만 엽니다). 자동 실행이 켜져 있으면 Windows에 다시 로그인해도 켜집니다.
- 설정을 바꾼 뒤 **다시 시작**하려면 트레이 아이콘의 **종료** → 시작 메뉴의 **leave-flow 휴가원 관리**. `update-config.ps1`은 값을 바꾼 뒤 알아서 다시 시작합니다 ([설정 파일](../configuration/index.md)).
