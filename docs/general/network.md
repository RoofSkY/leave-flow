# 네트워크 설정

## 고정 IP

출결 PC의 IP가 바뀌면 직원들이 접속할 수 없습니다. 출결 PC를 수동 IP로 등록하거나 공유기에서 IP를 예약해 두세요.

## 방화벽

- 설치할 때 Windows 방화벽에 `leave-flow` 규칙(해당 포트, **개인 네트워크에서만** 허용)을 만듭니다.
- 출결 PC의 네트워크가 "공용"으로 되어 있으면 다른 PC에서 접속할 수 없으니
  설정 → 네트워크 및 인터넷 → 이더넷(또는 Wi-Fi) → **네트워크 프로필 유형: 개인**으로 바꾸세요.

## 접속 주소

- 접속 주소: `http://<출결 PC IP>` (기본 포트 `80`은 생략. 다른 포트를 쓰면 `http://<출결 PC IP>:<포트>`)
- 직원 PC 브라우저에 **즐겨찾기**로 접속 주소를 등록해 두면 편합니다.
- 출결 PC의 IP는 명령 프롬프트에서 `ipconfig`로 확인합니다.

## 사무실 밖에서의 접속

사무실 밖(인터넷)에서는 접속할 수 없습니다. 공유기에서 포트 포워딩을 하지 마세요.

접속이 안 되면 [문제 해결 - 접속이 안 될 때](../troubleshooting/index.md#접속이-안-될-때)를 보세요.
