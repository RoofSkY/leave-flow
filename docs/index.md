# leave-flow

사무실 LAN에서 브라우저로 **휴가원**과 **시간외근무 신청서**를 작성·조회·출력하는 프로그램입니다.
서버 PC 한 대에 설치하고, 다른 PC에서는 `http://<서버 PC IP>:8082`로 접속합니다.
