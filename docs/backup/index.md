## 자동 백업

- 매일 `backupTime`(기본 12:30)에 DB를 `<설치 폴더>\backups`에 백업하고, `nasBackupDir`이 있으면 **NAS에도 복사**합니다.
- 그 시각에 PC가 꺼져 있었으면 켜진 뒤 바로 백업합니다.
- NAS가 잠깐 꺼져 있거나 응답하지 않아 NAS 복사에 실패하면, 그날 안에 **1시간마다 NAS 복사만 다시** 합니다.
  서버를 다시 켰을 때 오늘 자동 백업이 NAS에 없으면 그때도 NAS로 복사합니다.
- `backupKeepDays`(기본 30일)보다 오래된 백업은 자동으로 지웁니다 (`leave-flow-날짜-시각-….db` 이름의 파일만).

시각·보관 일수는 [설정 파일](../configuration/index.md)에서 바꿉니다.

## 백업 파일 이름

파일 이름 끝의 말로 언제 만든 백업인지 알 수 있습니다.

| 끝의 말       | 만든 때       |
| ------------- | ------------- |
| `daily`       | 자동 백업     |
| `manual`      | 지금 백업     |
| `pre-restore` | 복구 직전     |
| `pre-update`  | 업데이트 직전 |
| `pre-delete`  | 영구 삭제 직전 |

## 지금 백업

관리 → **백업·업데이트** → **지금 백업**: 바로 백업합니다 (로컬 + NAS).

## 엑셀 백업

관리 → 백업·업데이트 → **엑셀로 내려받기**: 직원, 휴가 종류, 부여 내역, 기존 잔여량, 휴가원, 휴가원 항목, 시간외근무 신청서,
공휴일·휴무일, 사용 현황 요약(올해), 변경 이력을 시트별로 담은 `.xlsx` 파일을 받습니다.
보관·확인용이며, **엑셀 파일로 복구할 수는 없습니다** (복구는 DB 백업 파일로).
