# 복구

## 관리 화면에서 복구

관리 → **백업·업데이트** → **백업 파일** 목록에서 원하는 시점의 **복구**를 누르면:

1. 지금 데이터를 먼저 백업하고(`pre-restore`),
2. 선택한 백업으로 바꾼 뒤 서버를 다시 시작합니다 (모든 직원의 화면이 잠깐 끊깁니다).
3. 그 백업 이후에 입력한 내용은 사라집니다. 잘못 복구했으면 `pre-restore` 백업으로 다시 복구하면 됩니다.

- 복구할 때마다 "복구 전" 백업이 두 개(복구를 누른 순간, 실제로 바꿔 끼운 순간) 생깁니다. 내용은 같으니 어느 쪽을 써도 됩니다.
- 최근 백업 일시·업데이트 기록 같은 시스템 정보는 복구해도 되돌아가지 않습니다.

## 서버가 시작되지 않을 때 직접 복구

1. 트레이 아이콘의 **종료**로 서버를 끕니다 (트레이가 없으면 관리자 PowerShell에서 `Stop-ScheduledTask leave-flow`).
2. 원하는 백업 파일을 `<설치 폴더>\data\restore-pending.db` 이름으로 복사합니다.
3. 다시 시작합니다. 서버가 시작하면서 지금 DB를 `backups\`에 보관하고 복구 파일로 바꿉니다.
