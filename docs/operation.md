# 운영

## 실행과 트레이

- 설치할 때 로그인해 있던 Windows 계정이 **로그인하면** 자동으로 켜집니다. 로그인하기 전에는 서버가 돌지 않으니 서버 PC는 운영 시간에 그 계정으로 로그인해 두세요.
- 켜지면 작업 표시줄 알림 영역(트레이)에 **파란 달력 아이콘**이 생깁니다 (안 보이면 `^`를 누름).
    - **웹페이지 열기**(아이콘 클릭도 같음): 이 PC에서 관리 화면을 엽니다.
    - **포트 바꾸기…**: 새 포트 번호를 입력하면 관리자 권한 확인 후 `config.json`·방화벽 규칙을 바꾸고 다시 시작합니다. 직원들의 접속 주소도 바꿔야 합니다.
    - **종료**: 서버를 끕니다. 다른 PC에서도 접속할 수 없게 됩니다.
- 다시 켜려면 시작 메뉴의 **leave-flow 휴가원 관리**를 실행합니다 (켜져 있으면 웹페이지만 엶).
- 서버는 그 Windows 계정으로 실행되고, NAS에도 그 계정으로 접근합니다.

## 접속 주소와 네트워크

- 접속 주소는 `http://<서버 PC IP>:<포트>`입니다 (기본 포트 `8082`). 서버 PC의 IP는 명령 프롬프트에서 `ipconfig`로 확인합니다.
- IP가 바뀌면 접속할 수 없으니 서버 PC에 고정 IP를 쓰거나 공유기에서 IP를 예약하세요.
- 설치할 때 Windows 방화벽에 `leave-flow` 규칙(개인 네트워크만 허용)을 만듭니다. 네트워크 프로필이 **공용**이면 다른 PC에서 접속할 수 없으니 **개인**으로 바꾸세요 (설정 → 네트워크 및 인터넷 → 이더넷/Wi-Fi → 네트워크 프로필 유형).
- 사무실 밖에서는 접속할 수 없습니다. 공유기에서 포트 포워딩을 하지 마세요.

## 영구 삭제

퇴사자는 보통 **비활성화**만 합니다. 잘못 만든 직원·휴가 종류를 정리할 때만 영구 삭제합니다.

- **직원·휴가 종류**: 비활성화한 뒤 `비활성 포함`을 켜고 `영구 삭제`를 누릅니다. 기록이 있으면 이름을 그대로 입력해야 지워지고, 지우기 직전에 자동으로 백업(`pre-delete`)합니다.
    - 휴가원·시간외근무 신청서는 지우지 않습니다. 작성할 때의 이름으로 계속 보이고 출력되며(수정·취소는 안 됨), 휴가원 양식의 휴가현황도 삭제 전과 같습니다.
    - 시간외근무 신청서에서 적립 종류로 고른 휴가 종류는 지울 수 없습니다.
- **휴가원**: 취소한 뒤 상세 창의 `영구 삭제`를 누릅니다 (지우기 직전 자동 백업).
- 잘못 지웠으면 `pre-delete` 백업으로 [복구](backup.md#복구)합니다 (그 뒤에 입력한 내용은 사라짐).
