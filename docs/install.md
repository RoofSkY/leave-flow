# 설치

## 설치 프로그램

1. `leave-flow-setup-<버전>.exe`를 실행합니다.
   "디바이스를 변경하도록 허용"에는 **예**, "Windows의 PC 보호" 창에는 **추가 정보 → 실행**을 누릅니다 (서명하지 않은 프로그램이라 나오는 안내).
2. 설치 폴더 기본값은 `문서\leave-flow`입니다. 문서 폴더가 OneDrive와 동기화되면 `C:\leave-flow`처럼 OneDrive 밖을 고르세요.
3. 다른 PC의 브라우저에서 `http://<출결 PC IP>:8082`가 열리는지 확인합니다 ([접속 주소와 네트워크](operation.md#접속-주소와-네트워크)).

설치 프로그램을 다시 실행하면 같은 폴더에 덮어 설치합니다 (데이터는 그대로). 낮은 버전으로 바꾸려면 [이전 버전으로 돌아가기](troubleshooting.md#이전-버전으로-돌아가기)를 보세요.

## zip으로 설치

다른 포트·폴더를 쓰거나 인터넷이 안 될 때는 `leave-flow-<버전>.zip`의 압축을 풀고 `scripts\install.cmd`를 더블클릭합니다.
옵션을 주려면 관리자 PowerShell에서 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Port 8090
```

| 옵션               | 뜻 (기본값)                                                         |
| ------------------ | ------------------------------------------------------------------- |
| `-InstallDir`      | 설치 폴더 (이미 설치된 폴더, 처음이면 `문서\leave-flow`)            |
| `-Port`            | 접속 포트, 5000은 사용 불가 (`8082`)                                |
| `-NasBackupDir`    | NAS 백업 폴더 (없음)                                                |
| `-UpdateRepo`      | 자동 업데이트할 GitHub 저장소 `owner/repo` (배포 파일에 적힌 저장소) |
| `-ReleaseZip`      | 배포 파일 경로 (스크립트가 있는 폴더)                               |
| `-NodeZip`         | 미리 받아 둔 `node-v24.x.x-win-x64.zip` (nodejs.org에서 받음)       |
| `-NoAutoStart`     | Windows 로그인 시 자동 실행하지 않음                                |
| `-DesktopShortcut` | 바탕화면 바로가기 만들기                                            |

## 처음 설정 순서

처음 설치하면 휴가 종류·직원·공휴일이 모두 비어 있습니다. 관리 화면에서 아래 순서로 입력합니다.

1. **휴가 종류**: 사무실에서 쓰는 종류를 모두 등록합니다.
   - 잔여 방식은 기록이 생긴 뒤에는 바꿀 수 없습니다. 연도별(해마다 새로), 누적(해를 넘겨 쌓임), 정한 날짜에 소멸(매년 그날 뒤 새로), 부여 후 기간(부여일부터 정한 개월 수), 소진(누적처럼 쌓이고 남은 양이 없으면 휴가원에서 숨길 수 있음).
   - 일부 직원만 쓰는 종류는 **적용 대상**에서 소속·구분·직원을 고릅니다. 소속과 구분을 함께 고르면 둘 다 맞는 직원만, 따로 고른 직원은 조건과 관계없이 대상입니다.
   - 대상마다 소멸일이 다른 연차는 `연차(직원)`·`연차(요원)`처럼 나눠 등록하고 **표시 이름**을 모두 `연차`로 합니다.
2. **설정**: 근무시간 기본값, 소속·구분 목록, NAS 백업 폴더. 사회복무요원 구분은 `사회복무요원 특별휴가 대상`을 켜야 특별휴가 신청서의 대상자로 나옵니다.
3. **직원**: 성명, 소속, 구분, 색상, 근무 요일·근무시간, 결재칸.
4. **기존 잔여량**: 프로그램을 쓰기 전까지의 올해 총 부여량과 현재 잔여량 (도입할 때 한 번).
5. **부여 내역**: 올해 부여량 (해마다 연초에 입력).
6. **공휴일·휴무일**: 공휴일은 서버를 켤 때 구글 캘린더에서 자동으로 들어옵니다. 빠지거나 틀린 날(대체·임시공휴일 등)이 없는지 확인해 고치고, 센터 휴무일은 **직접 추가**합니다.

양은 `[ ]일 [ ]시간 [ ]분`으로 넣고, **1일 = 그 직원의 하루 근무시간**(점심 제외)입니다.
시간외근무로 적립할 휴가 종류는 설정이 아니라 신청서를 쓸 때 대상자마다 고릅니다.

## 설치 폴더

```
<설치 폴더>\
  data\         DB (leave-flow.db) ← 가장 중요한 데이터
  backups\      로컬 백업
  logs\         로그
  config.json   설정
  versions\     프로그램 (버전별)
  node\         전용 Node.js
  그 밖의 파일   실행용 (tray.ps1, launcher.mjs, state.json 등. 고치지 마세요)
```

## 제거

Windows **설정 → 앱 → 설치된 앱**에서 **leave-flow 휴가원 관리**를 제거합니다 (zip으로 설치했으면 `scripts\uninstall.cmd`).
데이터·백업·로그·`config.json`은 남깁니다. 모두 지우려면 관리자 PowerShell에서 `uninstall.ps1 -RemoveData`를 실행합니다.
